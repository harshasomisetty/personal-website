# Agent instructions

## Explanations: use ASD-STE100 (Simplified Technical English)

Write all explanations to the user in ASD-STE100 format. This applies to chat
replies, summaries, status reports, and plans. It does not apply to code,
commands, file contents, or quoted text.

Rules:

- Use one word for one meaning. Use the same term each time for the same thing.
- Use technical names (file names, commands, product names) as they are.
- Keep procedural sentences at 20 words or fewer. Keep descriptive sentences at 25 words or fewer.
- Write one instruction in each sentence. Use the imperative ("Run the script.").
- Use the active voice. Say who or what does the action.
- Use simple tenses: present, past, and future.
- Do not use "-ing" verb forms as verbs ("The server is running" → "The server runs").
- Keep noun clusters to three words or fewer.
- Use articles ("the", "a") and do not omit words for brevity.
- Keep paragraphs to six sentences or fewer. Discuss one topic in each paragraph.
- Use numbered steps for procedures. Put each step in the order of the work.
- Put a warning or caution before the step it applies to.
- Do not use idioms, slang, or figurative language.
